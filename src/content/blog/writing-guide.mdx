이 글은 글을 쓸 때 참고하는 가이드이다. 각 항목마다 "작성"에 쓴 내용을 본문에 넣으면 그 아래와 같이 보인다. 이 글 자체도 같은 문법으로 썼으므로, 오른쪽(모바일은 위쪽) 목차와 각 요소의 모양이 그대로 예시가 된다.

## 글 정보(frontmatter)

파일 맨 위 `---` 사이에 글 정보를 쓴다. 파일은 `src/content/blog/` 아래에 `.mdx` 확장자로 둔다. `.md` 파일은 빌드에서 빠진다.

````yaml title="작성"
---
title: Spring 트랜잭션 동작 원리
slug: spring-transaction
description: Spring 트랜잭션의 내부 동작을 알아본다.
pubDate: 2026-10-20
updatedDate: 2026-10-21
draft: false
tags: [Java, Spring]
---
````

| 필드 | 필수 | 화면에서 쓰이는 곳 |
| --- | --- | --- |
| `title` | 예 | 글 제목(h1), 목록 제목, 브라우저 탭 제목 |
| `slug` | 예 | 글 주소 `/blog/<slug>/`. 영문 소문자, 숫자, 하이픈만 쓴다. 공개한 뒤에는 바꾸지 않는다 |
| `description` | 예 | 제목 아래 설명, 목록 설명(최대 2줄), 검색 엔진 설명 |
| `pubDate` | 예 | 게시일. 목록은 이 날짜의 최신순이다 |
| `updatedDate` | 아니오 | 있으면 글 머리에 "수정"으로 함께 표시한다 |
| `draft` | 예 | `true`이면 운영 빌드에서 빠진다. 개발 서버에서는 보인다 |
| `tags` | 아니오 | 글 머리의 태그 칩. 영문으로 쓴다 |
| `cover`, `coverAlt` | 아니오 | 목록 썸네일. 없으면 첫 태그로 만든 대체 표지가 나온다 |

## 제목과 목차

본문 제목은 `##`(h2)부터 쓴다. `#`(h1)은 글 제목이 차지하므로 본문에 쓰지 않는다.

````md title="작성"
## 큰 섹션

### 작은 섹션

#### 세부 항목
````

- `##`와 `###`은 목차에 들어간다. `###`은 목차에서 한 단계 들여 쓴다.
- `####`은 굵은 글자로만 보이고 목차에는 들어가지 않는다.
- 제목마다 주소 뒤에 붙는 앵커가 자동으로 생긴다. 예를 들어 "큰 섹션"은 `#큰-섹션`이 된다. 같은 제목이 반복되면 뒤에 `-1`이 붙는다.
- 데스크톱에서는 스크롤할 때 지금 읽는 섹션이 목차에 표시된다.

## 문단과 강조

빈 줄로 문단을 나눈다. 한 문단 안에서 줄만 바꾸면 화면에서는 한 줄로 이어진다.

````md title="작성"

````

코드 밖의 문장에 `<`나 중괄호를 그대로 쓰면 MDX가 코드로 해석해 빌드가 실패한다. 이런 글자는 인라인 코드나 코드 블록 안에 쓴다.

## 코드 블록

코드 블록은 macOS 창 모양으로 그려진다. 머리글에는 창 버튼, 파일 이름이나 언어, 복사 버튼이 있고 왼쪽에 줄 번호가 붙는다. 줄 번호는 복사할 때 섞이지 않는다.

### 언어만 지정

````md title="작성"
```java
public void transfer(long fromId, long toId, long amount) {
    accounts.withdraw(fromId, amount);
}
```
````

```java
public void transfer(long fromId, long toId, long amount) {
    accounts.withdraw(fromId, amount);
}
```

머리글 가운데에 언어 이름(`java`)이 나온다.

### 파일 이름 표시

언어 뒤에 `title="파일 이름"`을 쓰면 머리글에 파일 이름이 나온다.

````md title="작성"
```kotlin title="TransferService.kt"
@Transactional
fun transfer(fromId: Long, toId: Long, amount: Long) {
    accounts.withdraw(fromId, amount)
}
```
````

```kotlin title="TransferService.kt"

    accounts.withdraw(fromId, amount)
```

- 그림 번호와 캡션(그림 1. ...)을 붙이는 모양과 본문 이미지 저장 위치는 아직 정하지 않았다. 지금은 이미지만 넣는다.

## 자동으로 바뀌는 문장부호

Markdown 처리기가 일부 문장부호를 자동으로 바꾼다. 코드 안의 글자는 바뀌지 않는다.

| 작성 | 화면 |
| --- | --- |
| `--` | 짧은 줄표(–) |
| `"따옴표"` | 둥근 따옴표 |
| `...` | 말줄임표 한 글자(…) |

## 아직 쓸 수 없는 기능

- **알림 상자:** `> [!NOTE]`, `> [!WARNING]` 같은 GitHub 알림 문법은 아직 지원하지 않는다. 지금 쓰면 일반 인용으로 보인다.
- **각주:** `[^1]` 문법은 동작하지만 제목이 영어("Footnotes")로 나온다. 한국어로 바꾸기 전까지는 쓰지 않는다.
- **다이어그램과 수식:** Mermaid와 수식 문법은 켜지 않았다.
- **HTML 태그와 컴포넌트:** MDX라서 쓸 수는 있지만, 쓰면 그 글은 Keystatic 편집 화면에서 열리지 않는다.
